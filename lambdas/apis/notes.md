# Notes

* Categories must be entered before weights since weights are assigned to categories. If you try to enter weights before categories, you will get an error message.
* A competition can't be deleted once it has started since it will affect athlete results.
* Athletes can be marked as DNF to mark zeroing an event. They can be marked as withdrawn if they had to withdraw. If withdrawn all future event will be 0.
